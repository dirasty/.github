## 📌 Project Overview / نبذة عن المشروع

<div align="right">

مشروع **دراستنا (Dirasty)** هو منصة تعليمية رقمية متكاملة تهدف إلى تحويل المناهج الدراسية العراقية الورقية والنصية إلى مناهج رقمية تفاعلية لتسهيل وتطوير المنظومة التعليمية للطلبة والكوادر التدريسية.

</div>

**Dirasty** is an integrated educational web platform designed to digitize traditional Iraqi text-based curricula into an interactive digital experience, empowering both students and educators.

## 🛡️ Security & Data Architecture / الأمان وإدارة البيانات

<div align="right">

- 🔐 **نظام المصادقة:** دعم كامل لعمليات تسجيل الحسابات وتسجيل الدخول بحماية وتشفير عاليين.
- 🗄️ **قاعدة بيانات ضخمة ومؤمنة:** يعتمد المشروع على بنية تحتية لبيانات ضخمة ومخفية عن الوصول المباشر، لضمان أعلى معايير الخصوصية والأمن السيبراني.

</div>

- 🔐 **Authentication System:** Secure registration and login workflows for both students and teachers.
- 🗄️ **Enterprise-Grade Database:** Backed by a high-capacity, fully encrypted database infrastructure with hidden connection paths for total data privacy.
